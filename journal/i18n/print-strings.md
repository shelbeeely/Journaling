# Printed strings: where each lives

Generated by `node i18n/print-report.mjs` (BUILD-PLAN section 18, slice I1). **Nothing here is translated yet, and the print pipeline is unchanged**: this is the plan for slice I3,
which moves these words into catalogs with a `book.language` setting. `test-i18n.mjs` fails when this file is out of date.

How to read it: one block per file, then the function (or table) that holds the words, then the words. A heuristic found them (capitalised words and phrases in string
literals and between tags), so a few are not printed and a word built from pieces is missed. Not listed: the support, trans and clinic packs (`packs/`), which are written in the
pack's own language and never translated without a verified pack, scan codes and page ids (ASCII only), and the editor's words (`i18n/en.json`).
